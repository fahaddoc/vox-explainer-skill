# Script and voice

## Writing the script

**Audience:** Pakistan (and India), mostly on phones. They are smart but know nothing about the topic, and many read little English.

**Structure** (the container video: 52 lines, 710 words, about 4:20 of VO):
- **Hook (first ~15 s):** start mid-surprise. No greeting, no "is video mein hum dekhenge", no channel intro. The winning hook was a shock number with a contrast ("1956: $5.83 per ton → with the box 16 cents → 97% cheaper. Ek dabbe se itna farq kaise pad gaya?"), then a personal stake (your T-shirt crosses the sea for a few cents). Offer the owner 2-3 hook options (e.g. shock number / personal object / mystery) and let them pick.
- **Problem → mechanism → proof → consequences → twist → outro.** The middle must spell out the causal chain step by step, with a concrete picture for every step. Callbacks to the hook number in the proof section pay it off.
- **One "why" sentence the viewer can repeat.** Write it down before drafting ("pack once, lift the whole box → fewer workers, ship leaves sooner → port cost down"). Every line in the mechanism section should serve it. The clarity test in QA checks exactly this.

**Language:**
- Natural spoken Hindustani, the way a Pakistani explainer YouTuber talks: everyday Urdu/Hindi plus common English words (ship, container, port, truck, crane, company, trade, idea, system). No heavy Sanskrit Hindi ("vyavastha") and no heavy Persian Urdu ("tijarat-e-bahri"). Use "aap".
- **Full sentences** of mostly 6-14 words, made to be spoken. v1's verbless fragments ("Ek dabba. Ek size. Poori duniya.") confused viewers.
- **No jargon on the VO** (TEU, ISO, patent, twistlock). Say it plainly: "ek size", "kone ka taala".
- **Few numbers**, each tied to the story. Never two new numbers in one line unless it is a deliberate contrast.
- Soften uncertain facts: "lagbhag", "ek kitaab ke mutabiq", "ek research ke mutabiq". Use only facts in `research/facts-verdicts.md`; never invent quotes, dates or anecdotes.
- Prefer Urdu words where the English would be mispronounced: "Suez nehar" (canal), "janaaze" (funeral), "karobar" (trade, in VO).

**On-screen text** (`onscreen` field): short English, at most ~6 words, and only numbers the VO says in that line. See the plain-English list in SKILL.md.

## script.json schema

Generated by `script/build_<slug>.py`, copied from `scripts/build_script_template.py` (a Python list of tuples → `script.json` + the owner-read `script-<slug>.md`):
```json
{
  "title_options": ["...", "..."],
  "version": 2,
  "lines": [{
    "id": "L01", "section": "hook",
    "roman": "1956 mein, jahaz par ek ton maal chadhane ka kharcha tha: $5.83.",
    "onscreen": "1956 · LOADING COST: $5.83 / TON",
    "visual": "what the picture does on which word",
    "facts": ["F08"], "pause": 0.45,
    "pairs": [["1956", "उन्नीस सौ छप्पन"], ["mein,", "में,"], ["$5.83.", "पाँच डॉलर तिरासी सेंट।"]]
  }]
}
```
- `pairs` = [Roman display token, Devanagari TTS token]. The Roman side shows in captions and drives word sync. The Devanagari side is what Maya2 speaks. One Roman token may map to several Devanagari words (numbers, money).
- In the builder, the helper `T('roman|देव  roman|देव ...')` (pairs separated by two spaces) keeps lines compact.
- `pause` = silence after the line in seconds (0.3 normal, 0.45-0.7 before a reveal or new section).
- `section` drives YouTube chapters (`tools/make_description.py` `CHAPTER_NAMES`) and the act structure.
- Line ids are stable keys for TTS takes, so when inserting lines use suffixes (L15b, L17a) during editing, then renumber once at the end and remap takes by Devanagari text.

## Script critique (before any TTS)

Run `workflows/script-critique.js` (adapt CTX). Lenses:
- naive viewer: student, 19, Lahore. "Can you explain the WHY after reading this?"
- naive viewer: shopkeeper, 45, Karachi, little English.
- fact checker against `facts-verdicts.md`.
- Hinglish + pronunciation reviewer: flags English words Maya2 will mangle, unnatural phrasing, fragments.

Each proposed edit gets an adversarial skeptic. The container v2 accepted 39 of the proposed edits. Apply the accepted ones in `build_<slug>.py`, regenerate, and show the owner `script-<slug>.md`.

## Voice: Maya2 (Hindi model) via MLX

- Model `aruntemme/maya2-native-mlx-8bit` (mlx-audio 0.6.5) in `.venv-mlx`, voice **Anirban** (calm male documentary voice). It beat Kokoro, which mispronounced "economy" and "chhappan". Same voice on every video.
- Feed full Devanagari with numbers and money spelled out as words: `उन्नीस सौ छप्पन` (1956), `पाँच डॉलर तिरासी सेंट` ($5.83), `सत्तानवे परसेंट` (97 percent).
- Best-of-N: `--takes 3` per line, scored automatically. Listen-equivalent check: run Whisper on suspect clips (`tools/asr_check.py`) and read the text.

### Pronunciation fixes that worked (spell for the sound, not the dictionary)

| Word | Bad result | Devanagari that worked |
|---|---|---|
| horn | "hon" (`हॉर्न`) | `हार्न` |
| McLean | "Maakleen" | `मैक्लेन` (mak-LAYN) |
| $5.83 | digits read oddly | `पाँच डॉलर तिरासी सेंट` |
| New York | "Niyu Yok" | v2 used `न्यू यॉर्क` but it was not separately Whisper-verified: check that clip first |
| TEU | "T U" | don't say it: "bees foot ke dabbe" |
| Irina (ship name) | "Rina" | avoid names that need no story role; show them on screen only |

Rule of thumb: if an English proper noun matters, Whisper-check that clip alone. If it doesn't matter to the story, cut it from the VO and put it on screen.

### Voice gate

Before building shots on a new or changed take set, play one changed line next to the same line (or a similar one) from the previous video. Get the owner's OK. They noticed and objected to a voice drift on another channel.
